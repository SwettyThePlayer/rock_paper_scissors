# Rock Paper Scissors

A simple Rock Paper Scissors game built with Python. The project starts with the classic game and gradually expands its functionality, eventually including the extended Rock, Paper, Scissors, Lizard, Spock version.

## Features
1. Computer Choice: The computer randomly selects an option.
2. Player Choice: The player can choose their move.
3. Winner Detection: Compares both choices and determines the winner.
4. Input Validation: Checks player input to ensure only valid choices are accepted.
5. Score Tracking: Keeps track of scores and the number of rounds played.
6. Lizard and Spock: Expands the classic game with two additional choices.
## Game Rules

The classic version follows three rules:

Rock beats Scissors.
Scissors beats Paper.
Paper beats Rock.

The extended version adds Lizard and Spock:

Rock beats Scissors and Lizard.
Paper beats Rock and Spock.
Scissors beats Paper and Lizard.
Lizard beats Spock and Paper.
Spock beats Scissors and Rock.
## Project Development

The project was developed incrementally through the following steps:

1. Computer Choice: Implemented the computer's random choice.
2. Player Choice: Added the player's ability to select an option.
3. Winner Detection: Implemented the logic to determine the winner.
4. Input Validation: Added checks to validate player input.
5. Score and Rounds: Introduced score tracking and round counting.
6. Lizard and Spock: Expanded the game with two additional choices.

## How to Run
Make sure Python is installed on your computer.
Clone or download this repository.
Open a terminal in the project directory.
Run the game:
bash
python rps.py

## How to Play
Start the game.
Choose your move.
The computer randomly chooses its move.
The game determines the winner.
Check the score and play another round!
